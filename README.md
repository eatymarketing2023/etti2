# Yeti Burger Jumper

Ранний браузерный прототип 2D-платформера на чистом Canvas.

## Запуск

### Вариант 1: Python (есть почти везде)
1. Откройте терминал в корне репозитория.
2. Выполните команду `python -m http.server 3000` (можно другой порт, тогда замените цифру).
3. Перейдите в браузере на `http://localhost:3000` и откройте страницу `index.html`.

### Вариант 2: Node.js (через `serve`)
1. Установите Node.js (если ещё нет).
2. Из корня репозитория выполните `npx serve -l 3000 .`.
3. Откройте в браузере `http://localhost:3000`.

### Вариант 3: VS Code Live Server
1. Откройте проект в VS Code, поставьте расширение **Live Server**.
2. Кликните «Go Live» внизу окна — сервер запустится автоматически и откроет страницу в браузере.

> Прямое открытие файла `index.html` без сервера не рекомендуется: части API (например, звуки) могут блокироваться браузером при доступе по `file://`.

### Вариант 4: Встроенный Node-сервер (без зависимостей)
1. Убедитесь, что установлен Node.js 18+.
2. В корне репозитория выполните `node serve.js --port 3000` (порт можно поменять или передать через `PORT`).
3. Откройте в браузере `http://localhost:3000`.

> Скрипт `serve.js` использует стандартный `http`-сервер Node.js и не требует сторонних пакетов — удобно для быстрых демонстраций.

### Управление
- A/D или стрелки — ходьба
- W / ↑ / Space — прыжок
- Shift — спринт
- F — Морозное дыхание

## Что реализовано

- Базовое движение с ускорением, буфером прыжка и «coyote time».
- Морозное дыхание с кулдауном: замораживает кетчупных слизней и расходует морозную шкалу.
- Платформы, сбор бургеров и простая камера с параллакс-фоном.
- HUD со счётом бургеров и ресурсом морозного дыхания.
